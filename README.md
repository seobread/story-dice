# 상상 톡톡! 이야기 주사위

초등학교 1학년이 그림을 연결해 말하고, 듣고, 쓰고, 그리는 수업용 웹앱입니다.

## 실행하기

- `index.html`을 내려받아 Chrome, Edge 등 웹브라우저로 열면 사용할 수 있습니다.
- 설치, 회원가입, API 키, 별도 빌드 과정이 필요하지 않습니다.
- 태블릿과 교실 화면에서 같은 주소로 사용하려면 아래 GitHub Pages 설정을 완료하세요.

## GitHub Pages로 공유하기

1. 저장소의 **Settings → Pages**를 엽니다.
2. **Build and deployment → Source**를 **Deploy from a branch**로 선택합니다.
3. **Branch: main**, **Folder: /(root)**를 선택하고 **Save**를 누릅니다.
4. 배포가 완료되면 Pages 설정 화면의 **Visit site**로 실행합니다.

기본 게시 주소는 https://seobread.github.io/story-dice/ 입니다. Pages 설정과 첫 배포를 완료해야 열립니다.

## 수업에서 사용하기

1. **시작하기**를 누르고 혼자·짝·모둠 활동을 선택합니다.
2. 주사위를 굴려 그림을 뽑습니다. 마음에 드는 그림은 **고정하기**로 유지합니다.
3. 그림을 연결해 말합니다. 필요할 때 생각 질문이나 문장 시작 도움을 펼칩니다.
4. 글이나 그림으로 남기거나, 말하기만으로 활동을 마칩니다.
5. 작품을 기기에 저장하거나 활동지를 인쇄합니다. PDF는 인쇄 창에서 PDF로 저장을 선택합니다.

기본값은 그림 3장·혼자 활동·소리 끔입니다. 선생님 설정에서 그림 2장/3장/5장, 사용할 카드, 그림만 보기, 활동 종류, 타이머 등을 바꿀 수 있습니다.

## 주요 기능

- 누가·어디서·무엇으로·무슨 일이·어떤 마음, 다섯 종류 각 16장(총 80장)의 자체 SVG 그림
- 카드별 다시 뽑기, 카드 고정, 목록에서 직접 선택
- 혼자·짝·3~6명 모둠 활동과 차례 넘기기
- 생각 질문, 선택형 문장 시작 도움, 지원 기기에서 한국어 낱말 듣기
- 자유 글쓰기/처음·중간·끝 글쓰기, 그림판, 되돌리기
- 최근 작품 목록, 현재 활동 복원, JSON 백업·가져오기
- A4 인쇄용 활동지, 선택형 타이머, 움직임 줄이기

정답·점수·순위·자동 이야기 생성·자동 채점은 없습니다.

## 저장 안내

작품은 **현재 기기의 현재 브라우저**에 저장됩니다. GitHub로 학생 작품이 전송되거나 기기 사이에서 자동으로 공유되지 않습니다. 브라우저 데이터 삭제, 시크릿 모드 종료, 다른 기기 이용 시 저장한 작품을 볼 수 없을 수 있으므로 필요한 작품은 백업 파일로 보관하세요.

앱 코드는 GitHub에 저장되며 작품 데이터와 별개입니다. 낱말 듣기는 기기와 브라우저의 음성 기능을 사용하므로 지원 여부가 다릅니다.

## 확인 범위

자동 검사와 데스크톱 브라우저에서 카드 뽑기·고정·개별 다시 뽑기, 직접 선택, 카드 수 변경, 글 입력, 마우스 그림, 저장 후 새로고침 복원, 모둠 차례 넘기기, 한국어 음성 미지원 시 안내를 확인했습니다. 390px 너비 화면도 확인했습니다.

실제 태블릿 터치, 실제 한국어 음성 출력, 종이/PDF 인쇄 결과는 해당 기기에서 추가로 확인해야 합니다.
